buildAllDebug
    Компилирует проект с использованием конфигурации отладки. (Дебаг) 
buildAllRelease
    Компилирует проект с использованием конфигурации игрового сервера (Релиз)
buildAllTools
    Builds all projects with tools configuration

Сборка debug, release - это просто то, что люди разрабатывают на самом сервере.
Сборка release содержит различные оптимизации, в то время как сборка debug содержит инструменты отладки.
Если вы проводите сопоставление, используйте сборку release или tools, так как это будет работать более плавно и с меньшим количеством сбоев. Для сервера в Хабе используется Release.


runQuickAll
    Запускает клиент и сервер
runQuickClient
    Запускает клиент
runQuickServer
    Запускает сервер

runTests
    Запускает модульные тесты, проверяет, работают ли различные системы на C# должным образом
runTestsIntegration
    Запускает интеграционные тесты, проверяет, работают ли различные системы на C# должным образом
runTestsYAML
    Запускает yml linter и обнаруживает проблемы с файлами yml, которых в противном случае, вероятно, не было бы
